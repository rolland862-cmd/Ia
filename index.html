Héberger sur GitHub & Créer l'APK

1 Mise en ligne gratuite sur GitHub Pages

  1. Vérifiez vos fichiers dans votre dépôt public Ia (index.html, manifest.json, icon-192.png, icon-512.png).
  2. Dans Settings > Pages, vérifiez que la branche main (/ (root)) est active.
  3. Votre URL publique est https://rolland862-cmd.github.io/Ia/.

2 Transformer en fichier APK pour Galaxy S26 Ultra

  1. Ouvrez pwabuilder.com et collez https://rolland862-cmd.github.io/Ia/.
  2. Cliquez sur Package for stores puis sélectionnez Android.
  3. Téléchargez le package généré et installez l'APK sur votre S26 Ultra.
